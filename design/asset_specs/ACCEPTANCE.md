# 资产验收与当前交付边界

## 已交付基底的验收

- 30 个 UI SVG 与 11 个占位 SVG 均应存在，UTF-8 XML 可解析，width／height 与 viewBox、manifest 一致；asset_id 不重复。
- 角色和道具占位 SVG 有分层 group、固定 pivot；UI 底板没有烘焙文字和数字。SVG 没有脚本、外链图片、嵌入第三方字体或整张原型截图。
- 清单每项必须用真实现存包内相对路径，或在 `planned` 时 `path:null`。概念图不标为 production，不从其裁切获得 runtime assets。
- `design/source/validate_asset_foundation.py` 在从包中移走到任意目录后仍可运行；读取路径由脚本位置推导，不依赖本次工作区绝对路径。

当前 11 个游戏 SVG 都是明确标注的占位：4 个角色姿态，7 个道具／场景。其简单矢量线条没有达到正式 3D 绒羊质感，且没有完整八方向和动画，不能据此通过最终角色美术验收。

## 正式生产美术验收（T-050／T-051）

| 范围 | 必须通过的检查 |
|---|---|
| 形象一致 | 四原型和外观板的奶白绒块、暖脸、短弯角、红围巾、单金铃一致；不同相机仍是同一羊 |
| 方向 | 羊／狗各八向完整，与 0E..7NE 表一致；不将外观板下排视角冒充精确方向 |
| 动画 | 侧视 38、羊八向 104、狗八向 112 生产帧齐；动作名、fps、循环标记正确；root 不移动 |
| 尺寸 | 源 256、图集 128 的固定画布和 pivot；没有自动中心化、剪脚／角／铃或逐帧缩放 |
| 图集 | 内容边界不越页、无出血、透明边无色边、无烘焙阴影；JSON 正确描述 rect 和 pivot |
| 真实资源 | `.blend`、脚本、原始帧、atlas PNG／JSON 实际存在、可重建；planned 状态有证据才能更新 |
| 来源 | 用户参考仅风格；原创／生成／第三方来源分开登记，任何后续外部资源的许可经归档后才纳入 |
