# T-050／T-051：程序化可编辑母源与生产图集任务书

## 当前状态

未交付 `.blend`、完整 Blender 建模脚本、生产动画帧或角色图集。已交付的是本任务书、角色概念板、参数／接口及 41 个原创 SVG 基底。Codex 可以据此开始创建可编辑母源；不得把占位 SVG 或概念板切片当作已实现母模型。

## 必须交付的母源

1. `art-source/sheep_master.blend` 与生成／修订脚本：同一羊模型、可调几何和材质、绑定、全部侧视／八向动作。
2. `art-source/dog_master.blend` 与生成／修订脚本：明确不同轮廓的棕白牧羊犬、绑定、idle／walk／bark。
3. `art-source/farm_master.blend` 与脚本：草垛底托、栅栏、栏杆、福草叶与金芯、农舍、地面素材；侧视／斜俯视共用材质。
4. `art-source/render_assets.py`、可机读 render plan、README 和来源记录；一条本地命令可在指定 Blender 版本批量导出透明帧，再打包图集。生成后资源目录、PNG／JSON 才能登记为现存文件。

上述名称为未来文件名。本包的 baseline manifest 对这些项保持 `path:null`；美术在正式仓库制作后按实际路径更新清单。

## 场景结构

使用可读集合 `CHAR_SHEEP`、`CHAR_DOG`、`ENV_FARM`、`RIGS`、`CAMERAS`、`LIGHTS`。羊对象分层 `body_wool`、`face`、`horns`、`ears`、`tail`、`legs`、`hooves`、`scarf`、`bell`；狗同理分出 body／head／ears／tail／legs／collar。围巾与铃是几何对象，不能画在只有一个方向正确的脸贴图上。

羊毛用少量可调的圆润大绒块建立轮廓，近看有体积，缩至游戏实际尺寸仍清楚；不要求昂贵毛发模拟。保留可编辑材质节点：wool、face、horn、hoof、scarf、bell。参数集中到配置，便于换企业主题色；不得引入不可追踪来源的外部角色或材质包。

角色 root 在脚下地面中心，无 root motion；骨骼／对象命名稳定。绑定动作 `idle/run/takeoff/air/land/steady/bump/celebrate` 与八向 `idle/walk/enter/bark` 按相机规范执行。动画只做相对摆动，不移动 root；跑跳位移由游戏逻辑提供。

相机按 `CAMERAS_AND_ANIMATION.md` 的坐标、投影和固定裁剪；所有方向由同一绑定模型旋转，灯光不跟随模型旋转。颜色管理和曝光统一并锁在脚本中。平面背景透明，接地阴影单独输出；素材无 UI、文字、数字、Logo 或水印。

## 制作阶段与审查点

| 阶段 | 产出 | 准入条件 |
|---|---|---|
| A 轮廓与材质 | 一张正面／侧面／背面／8 向静态对照 | 同一羊、单只金铃、短弯角、背面无错脸；与概念板的体积、绒块和颜色一致 |
| B 动作 | 独立动作预览、root 十字与地面网格 | 无脚锚点漂移、无穿插、同方向不同动作尺度一致 |
| C 批渲染 | 254 个生产角色帧及环境素材 | 固定画布、透明底、八向齐、命名齐；未混入任何原型切片 |
| D 图集 | PNG、atlas JSON、渲染记录与校验值 | 按图集合同、帧数和预算检查通过 |
| E 游戏集成 | 三游戏实际页面和真机记录 | UI 分离、数值正确、地面／门／障碍对齐、不改物理 |

## Codex 执行要求

先确认可用 Blender 版本，固定版本后将其写进 README；未实际运行时不得声明“已导出”。可写程序化建模脚本作为起点，但要实际打开／渲染检查。将随机绒块的种子固定在美术源配置，不共用游戏 seed 或 RNG。离线渲染可以较慢，运行时只加载 2D 资源，不依赖浏览器实时 Blender 或每帧 3D 毛发。

建议以 128 生产帧／256 可编辑渲染源的双尺寸保留清晰度。放大图集、换相机或调整轮廓需要所有方向统一重导；不得只修某一帧导致尺寸和朝向漂移。旧图集保留版本，替换后完整重放黄金输入，确认只有画面变更。
