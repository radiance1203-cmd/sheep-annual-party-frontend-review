# 相机、方向、画布和动画接口

版本：art-baseline-1.0.0。以下生产规格尚待 Blender 制作；现有 SVG 只提供同一画布和 pivot 接口。所有像素坐标以左上为 (0,0)，x 向右、y 向下。

## 1. 命名与方向

逻辑地面为 x 向右、y 向下。母模型 Blender 坐标 Z 向上；羊鼻子在绑定姿态朝本地 +Y。离线渲染时相机不动、角色绕 Z 轴转向：

| direction | 后缀 | 游戏地面方向 | 母模型 Z 旋转（度） |
|---:|---|---|---:|
| 0 | e | 右 | -90 |
| 1 | se | 右下 | -135 |
| 2 | s | 下／朝镜头 | 180 |
| 3 | sw | 左下 | 135 |
| 4 | w | 左 | 90 |
| 5 | nw | 左上 | 45 |
| 6 | n | 上／背向镜头 | 0 |
| 7 | ne | 右上 | -45 |

该表同时适用于羊与狗。生产八方向分别渲染，禁止用镜像造成围巾结、铃、尾或受光反转。图集键名例：`sheep_iso8__walk__n__f005`；帧号从 f000 起连续。侧视仅交付向右 e，叠高高的横向漂移不需让脸随每次边界反弹翻转。视觉朝向选择不消费逻辑随机数，静止保持上一朝向，赶羊初始无朝向时用 n。

## 2. 固定相机和锚点

| 参数 | side_v1（叠高高／跨栏） | iso8_v1（赶羊） |
|---|---|---|
| 投影 | 正交，近侧视 | 正交，斜俯视 |
| Blender 相机位置 | (0,-8,1.4) | (0,-6,6) |
| 看向点／相机 roll | 地面原点 (0,0,0)／0 | 地面原点 (0,0,0)／0 |
| 仰角 | atan(1.4/8)，约 9.926° | 45° |
| 源渲染 | 512×512 RGBA 透明 | 512×512 RGBA 透明 |
| orthographic_scale | 4.0 | 32/7，约 4.571428571 |
| 固定裁剪 [x,y,w,h] | [128,32,256,256] | [128,60,256,256] |
| 交付源单帧 | 256×256 | 256×256 |
| 源 foot／ground pivot | [128,224] | [128,196] |
| 默认生产图集单帧 | 128×128 | 128×128 |
| 图集 pivot | [64,112] | [64,98] |

相机局部 -Z 对准目标，局部 Y 作为上方向。世界原点投影在 512 图中心，固定裁剪因此得到指定 pivot。保持此机位、root 和裁剪规则，不按每一帧的透明边界重新居中。侧视 pivot 是地面上 root 的投影，斜俯视 pivot 是角色底部地面中心的投影，不是最下方不透明像素；斜俯视朝镜头的前蹄可以自然低于该中心。

母源以原点为地面 root，无动画 root motion；默认羊总高约 1.4 Blender 单位、躯干长约 1.1、宽约 0.9，最终比例以角色板核准。姿态须落在 256 单帧安全区内，至少留 8 源像素透明边。若几何越界，先调整同一母源和所有动作的共同尺度，不能独立缩小某个方向或某一帧。

美术相机仅用于把单个角色和道具渲染成精灵。游戏地面保持规则的二维坐标；赶羊的 360×420 场地、入口与输入映射不因为 iso 相机自动压缩 y，也不应用未定义的等距投影。各精灵在前端按逻辑地面点摆放，背景平面由可拼接素材组装。若产品未来要整体投影，必须单独审批全场统一变换和逆变换，不能在素材接入时悄悄增加。

## 3. Runtime 尺寸与物理独立

推荐起始显示：128 图集帧绘制为 64×64 逻辑单位，源 SVG 256 以 0.25 比例绘制；侧视 pivot 映射为 [32,56]，斜俯视为 [32,49]。这是一致的初始视觉尺寸，验收可以按整类资源调整显示比例，但不能改碰撞尺寸。侧视跑羊脚锚点绑定 runner 的脚坐标；叠高高羊脚绑定草垛顶部，草垛底托为固定 112 逻辑宽，不剪羊、不逐层缩窄。

赶羊羊中心半径 10、狗半径 9；羊／狗插画可超出圆形碰撞轮廓，不能把“毛团的透明边界”当碰撞圆。游戏需要清晰显示原规则栅栏 y=76、入口 x=144..216（羊心通道 x=154..206）；正式栅栏立柱不能向通道内加厚到造成视觉与碰撞不一致。跨栏障碍的高度与宽度来自配置，福草外圈与金芯分别对应其取分半径。联调提供可开关碰撞调试层，正式画面关闭。

所有生产帧无烘焙阴影。接地阴影独立放在地面点；跳跃时按逻辑高度缩小／变淡，不让阴影和角色同幅跳起。地面角色按脚点 y 排序、相同 y 用稳定 actor ID；栅栏前后段分层以防盖住入口提示。视觉插值与相机跟随仅改变表现。

侧视 38 帧、羊八向 104 帧、狗八向 112 帧，共 254 个生产帧；本包实际动画帧数为 0，41 SVG 中的角色只有静态占位姿态。

事件优先级：已结束／已入圈按逻辑状态处理，其次合法碰撞反馈／吠叫，再起跳或落地，再运动，再 idle。动画可以提前结束、切换、重采样；动画帧完成回调绝不产生跳跃、移动、成功、分数、冷却或结束事件。计时使用 30Hz 逻辑时间；渲染可 30／60fps，装饰插值不能改变输入 tick。

## 5. 灯光和材质约束

场景统一暖白大面积柔光，画面左上较亮，阴影柔和、低对比；所有方向使用同一世界灯光。使用大块可读绒团，避免单根毛发闪烁。羊毛暖白，角和脸分材质，围巾朱红、单只金铃暗金。素材渲染为 sRGB、RGBA8、透明底，导出后检查无黑边／白边。输出颜色管理、曝光、材质参数写入母源脚本和渲染记录；同一图集不得混用曝光和白平衡。
