# 第三方代码来源与许可

本前端快照保留主项目许可总表作为来源记录；实际前端安装范围以本仓库package-lock.json为准，后台实现未上传。

实际安装版本与锁文件一致。项目业务实现未拷贝第三方游戏逻辑；Blender 仅作为离线制作工具。角色/牧场/UI/合成提示音的原创制作记录另见 art-source/README.md 和 design/asset_specs/SOURCE_REGISTER.md。
