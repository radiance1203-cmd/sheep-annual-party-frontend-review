R04：累计层数、距离/越栏/外圈/金芯、入圈数位于独立稳定区域，短反馈另显2.2秒。每step完整有序events与该step只读view交给presenter，不再find第一条事件代替全部。

表现层：Phaser4.2.1本地源码确认FIT支持setGameSize；backing buffer按实际CSS尺寸×有效DPR，采用DPR上限2并公开请求/采用值；一个Phaser更新入口负责只读表现时钟，结束不暂停Scene、不等待动画才提交。方向和步相分开，步频使用实际位移，起跳takeoff只覆盖短起跳相位。稳定actor/prop ID复用对象，阴影独立、足点排序、32个特效池、512条滚动事件诊断，装饰省略原因明确。现有shared效果实际接入。新SE walk+bark仅在显式局部预览加载；其余方向缺组合时保留走腿，并明确标记头部组合未制作，不冒充完整吠叫动作。

事件信封为sessionId/epoch/tick/原数组序号，记录原event_key；同tick同对象同类型不会合并。重练清队列、时钟和特效；恢复只重建现态，不重播历史。正式原时轴、结算、幂等与身份路径不改。
