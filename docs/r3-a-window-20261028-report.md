## 失败方法与具体调整

- 首轮绑定旧root动作覆盖了设定方向，标签不正确。错误首样保留，采用delta rotation补足方向，原动作不改；错误标签图未接入。
- 材质首样sheen过高使围巾／犬毛泛白。一次复修降低sheen，未增加毛数、毛长或采样；犬仍光滑，已承认本方法不能单靠shader达到原型毛簇，不继续堆参数。
- 背景首次柔化层有矩形边缘，保留被拒绝轮并加横向渐隐。独立整屏复审又发现赶羊stage顶非零mask造成硬起点；总控只将该纵向mask改为从透明渐入，保留修正前全部27图，再重拍最终27图并全部独立重新开图。
