- 目标羊宽84、高58.154，保持182:126原始轮廓；托宽仍112，羊托比75%。保留2间隙与6托厚，最小整数显示层距为 `ceil(84×126/182+8)=67`。

- 移动托盘、落地、阴影、反馈和相机全部使用同一映射。移动托初始在支撑上方3层；相机支撑锚当前209.6不足，拟试约270，顶部余量约 `270−3×67−58.154−2=8.85`。必须检查整个swing包络和全部动作，不以这个单一算式宣称无裁切。
- 收益：羊占托宽75%，仍低于原型近等宽；材质另验。若希望宽100，最少78显示层距；宽112至少86。先不并入更大选项。

- 测试：20层与±56/±6.72边界、极端横移、12tick下落/6tick停稳、三终局、相机/层间穿插/画面全包络；同输入每tick core结果一致；三屏/DPR；真人落点预判对照。未获批准不实现。
