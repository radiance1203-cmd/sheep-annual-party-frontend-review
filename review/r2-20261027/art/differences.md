## 参考差异与处理

| 维度 | 当前有限候选 | 相对原型仍有的差距 / 下一次有限样板要验证 |
|---|---|---|
| 羊身份与表情 | 保留奶白绒毛、浅脸、红巾和单铃；眼与脸可辨 | 脸部仍偏平、侧面脸部面积小；卷角的轮廓与分节仍欠原图的粗短感；须继续雕塑当前母样，不能靠扩帧掩盖 |
| 绒毛 | 融合体积减少独立球瓣硬缝，增加小幅轮廓不规则与细绒 | 局部仍有糊团感，前额轮廓欠自然；最终 55–64 CSS px 仍弱于参考，DPR 不能解决造型 |
| 团坐 | 采用真正关节屈腿、相同 root 和透视，面部向镜头转 | 同样板实测 alpha 高度必须保留层间净空；原图胖羊近似托盘宽仍与 112/44 冲突，不把此图自动当新原型 |
| 犬 | 移动腿与吠叫叠加有真实帧变化，没有用静止 bark 覆盖腿 | 身体毛层过光滑、口部振幅与耳回落不足；只一个 se 方向，八向连续性 NOT_RUN |
| 场景 | 同源牧场斜俯视实验，保留二维游戏地面；场边有体积 | 仍大片平绿、层次和木草材质不及参考；只 herd 小样，stack/runner 仍沿用 v4，不得称三场景升级完成 |
| 动态 | 一个 8 帧犬合成片段，原生 Actions 可编辑 | 羊跑/跳/落地/接触/入圈尚未制作，环境循环和前后景拆层尚未制作 |
