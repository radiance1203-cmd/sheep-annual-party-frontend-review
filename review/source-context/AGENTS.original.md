# 羊年年会现场游戏平台

## 目标与入口

交付包版本为 V2.2，游戏规则仍为 `onsite-v2.1-candidate`。实现一次公司年会现场的三款游戏及共用后台。先读 `00_README.txt`、`docs/PRD.md`、`planning/DEVELOPMENT_PLAN.md` 与 `04_CODEX_START_PROMPT.txt`，然后按任务读取细则。这里提供的是开发基底，不代表应用已经实现。

## 不变量

- 三款全部实现；每人整场共用 3 槽，任意选择、允许重复。有效自然终局且有有效操作、准时完整提交并核验后，单局 20 参与分加 0 至 80 表现分，全场最多 300。无按日刷新。
- 数值来源仅为 `config/game_rules.v2.1.json`；算法及取整顺序见 `02_GAME_RULES.txt`。三款 seed 分别为 1、1、47。不得混入 audit 下历史参数。
- `07_RUNTIME_AND_OPERATIONS.txt` 定义预约、时钟、日志、幂等、原槽补场、封榜、租约、订单与领取边界。contracts 必须与它一致；有冲突先修复受影响契约并记录，不能自行选择较容易的含义。
- 纯 TypeScript `packages/game-core` 是浏览器与 Node 重放共用的唯一规则内核；Phaser 只负责表现。前后端不得另写计分或碰撞。game-core 不读取 DOM、Phaser、墙钟、网络或未设种子的随机数。
- 正式局 start 成功占槽并预约 3 秒；正式开赛起最多 45 秒；完整提交截止为开赛后 60 秒。时间和初值不能因重试、刷新或换设备重置。
- 榜单只按有效总分并列排名；兑换不降低荣誉分。默认一人一件，真实事务扣分、预留、核销，成功核销后才交实物。

## 协作

保留一个总控入口。优先把边界清楚的工作交给实际可调用的子代理；不可调用时同一主会话按依赖顺序继续，不能停下来要求用户手动调度。遵循 `docs/CODEX_WORKFLOW.md` 和 `planning/OWNERSHIP.csv`。

总控独占规则、game-core、contracts、根依赖与锁文件、共享工程配置和最终集成；美术负责制作源与素材；前端负责 apps/web 源码；后端负责 apps/server、数据库迁移和自身测试。迁移按冻结的数据契约由后端单一作者实现。禁止跨边界重写其他角色代码。

不要假设子代理自动隔离文件。并行写任务先记录实际 checkout、基线提交、文件范围和返回格式。独立会话使用不同 Git worktree；没有隔离时不同目录且同一文件只有一个写入者。禁止多个代理同时运行 Git 索引变更、依赖安装或重写锁文件。总控统一集成和提交。

已有用户改动保留；不执行清空、强推、重置现有工程。资料包合入现有仓库时合并既有 AGENTS 指令，不能覆盖用户规则。

## 验证与推进

先核对真实环境，再实现契约、三款模拟核及灰盒、叠高高正式闭环、三款表现层、后台兑奖、集成验收。按计划持续完成可逆的本地开发；不在每个阶段重复索要确认。按实际环境查证依赖版本并锁定，不使用浮动 latest。

当前数学基底可先运行 `python acceptance/verify_package.py`。新增工程后建立并实际执行计划中的 typecheck、build、core、PostgreSQL、浏览器与并发测试。只记录真正运行过的结果。

更新 `planning/PROJECT_STATE.json`、`docs/implementation-log.md`、`docs/test-report.md`；这些是本项目的状态文件，并非 Codex 自动执行协议。长会话在阶段边界写清下一任务、依赖、提交和未验事项后再续接。

素材状态必须真实。原型和角色设定板是外观参考；SVG UI 可接入；角色占位 SVG 不算最终绒毛质感图集。禁止整张截图覆盖按钮代替游戏。素材与规则坐标分离，静音可玩，主要触区至少 48 CSS px。

真人难度、真实手机、现场网络、正式活动信息与最终视觉未通过时阻止正式启用，不阻止其他开发。禁止伪造真人数据、把视口模拟写成真机通过，或用内存余额、随机分数和假库存冒充真实闭环。不得擅自购买服务或公开部署。
# visual-repair-v1 局部解释（2026-10-27）

本轮参考原型同时约束构图、材质、角色与层次，规则几何仍仅来自 game-core。补充包提供的局部 hero/玩法封面可作为 img；不得把整张页面截图代替界面。固定品牌艺术标题可烘焙并保留语义标题，动态业务数据与按钮保持真实组件。角色方向/动作沿用并修复现有 3D 母源；插画不依赖母模。唯一当前运行清单为 apps/web/public/assets/asset-manifest.v1.json，旧版只作不可变兼容快照。保留既有源码、母源与资源，不用旧生成器覆盖已完成工件。视觉与现场门槛分开记录，实际开图验收不能由测试数量替代。详细冲突映射与边界见 docs/visual-repair-v1-plan.md。
